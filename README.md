# @nifdi/mcp

The closed-source MCP server and visual editor behind
[nifdi](https://nifdi.app), for creating and editing structured `.nifdi.svg`
diagrams with coding agents.

For most users, the entry point is the
[nifdi plugin](https://github.com/nifdi-app/nifdi-plugin). It installs this
package together with the diagram-authoring skills and includes setup
instructions for Codex, Claude Code and other MCP clients.

## About this repository

This is a placeholder repository for the published `@nifdi/mcp` package. It
does not contain the server or editor source code.
